# Законы Республики Казахстан — правовой помощник

Цель: быстро находить **действующую** редакцию любой нормы права РК и цитировать её со ссылкой на первоисточник.

## Как это работает

Тексты законов здесь **не хранятся** — их берём в момент вопроса с официальной ИПС «Әділет» (adilet.zan.kz,
оператор — Институт законодательства и правовой информации Минюста РК). Поэтому ответ всегда по актуальной
редакции, и «обновлять» ничего не нужно.

Почему не полная копия базы: robots.txt сайта (проверен 08.10.2026) закрывает `/api/` и поиск для всех роботов
и прямо запрещает ИИ-краулерам массовую выгрузку. Открывать отдельную страницу акта по просьбе человека —
разрешено. Официальный доступ к выгрузке запрошен письмом в ИЗПИ; если его дадут — сделаем локальную библиотеку
с автообновлением.

## Что здесь лежит

- [katalog.md](katalog.md) — Конституция 2026 года, конституционные законы, все кодексы с идентификаторами и ссылками.
- `.claude/skills/zakony-rk/SKILL.md` — порядок работы Claude с правовыми вопросами (подхватывается автоматически).

## Как спрашивать

Обычным языком: «Какой срок исковой давности по ГК?», «Что изменилось в ст. 188 УК?»,
«Найди закон о персональных данных». Claude найдёт акт, откроет его на adilet и процитирует статью со ссылкой.

## Что нужно настроить

1. **Доступ к сайту.** В облачном окружении Claude добавьте `adilet.zan.kz` в разрешённые домены:
   меню окружения в заголовке сессии → Edit → Network access → Allowed domains
   ([инструкция](https://code.claude.com/docs/en/cloud-environments#network-access)).
   Без этого Claude может дать только ссылку и ответ «по памяти» с пометкой, что он не сверен.
2. **Ветка по умолчанию.** Чтобы правила работали в новых сессиях, эти файлы должны быть в основной ветке репозитория.

## Обновление каталога

Новые кодексы и отмены вносятся в `katalog.md` вручную — достаточно попросить Claude:
«проверь, не появились ли новые кодексы». Каталог — справочник для навигации, а не источник текста.

## Оговорка

Это инструмент для учёбы и навигации, а не юридическая консультация. Для официальных целей сверяйте текст
на adilet.zan.kz.
