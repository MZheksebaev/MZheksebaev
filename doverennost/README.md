# Доверенности на водителя

Генерирует доверенность ТОО «Zhebe Logistics» по PDF-шаблону: подставляет дату,
тягач и прицеп, данные водителя, маршрут и срок действия (всегда +10 дней).
Шапка, водяной знак, печать и подпись берутся из шаблона без изменений.

## Установка

```bash
pip install -r requirements.txt
```

Положите любую ранее выпущенную доверенность клиента в `templates/`,
например `templates/coca-cola.pdf`. Папка `templates/` и результаты в `output/`
в git не попадают: там печать, подпись и персональные данные.

## Запуск

```bash
python generate.py --template templates/coca-cola.pdf \
  --truck-brand VOLVO --truck-plate 099YSZ13 --trailer-plate 99AAT13 \
  --driver "Фамилия Имя Отчество" \
  --iin 770819302940 --doc-number 040849175 --doc-date 07.11.2016 \
  --from Алматы --to Жетысай
```

В доверенности это превращается в `VOLVO 099YSZ13/99AAT13` (марка прицепа
не пишется) и `Алматы-Жетысай`.

Параметры по желанию: `--date ДД.ММ.ГГГГ` (по умолчанию сегодня), `--out путь.pdf`.

Перед генерацией данные проверяются: контрольная цифра ИИН, номер документа
(9 цифр у удостоверения личности или 8 цифр у паспорта), формат даты выдачи, госномера (кириллица вроде «А», «С», «Т»
автоматически заменяется на латиницу). Отключить проверку: `--force`.

Шрифт Open Sans (`fonts/`) распространяется по лицензии Apache 2.0.

## Веб-приложение

`web/` — страница для claude.ai: загрузка фото → Claude считывает данные →
проверка полей → PDF собирается прямо в браузере (pdf-lib) поверх пустого
шаблона. Журнал выданных доверенностей хранится в браузере и выгружается в CSV
для Excel. Пустой шаблон с печатью загружен в защищённое хранилище артефакта
и в репозиторий не попадает. `web/poa.js` повторяет правила `generate.py`.
