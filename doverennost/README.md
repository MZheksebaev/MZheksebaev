# Доверенности на водителя

Генерирует доверенность ТОО «Zhebe Logistics» по PDF-шаблону: подставляет дату,
автотранспорт, данные водителя, маршрут и срок действия (по умолчанию +10 дней).
Шапка, водяной знак, печать и подпись берутся из шаблона без изменений.

## Установка

```bash
pip install -r requirements.txt
```

Положите любую ранее выпущенную доверенность клиента в `templates/`,
например `templates/coca-cola.pdf`. Папка `templates/` и результаты в `output/`
в git не попадают: там печать, подпись и персональные данные.

## Запуск

```bash
python generate.py --template templates/coca-cola.pdf \
  --vehicle "VOLVO 099YSZ13/99AAT13" \
  --driver "Фамилия Имя Отчество" \
  --iin 770819302940 --doc-number 040849175 --doc-date 07.11.2016 \
  --route "Алматы-Жетысай"
```

Параметры по желанию: `--date ДД.ММ.ГГГГ` (по умолчанию сегодня),
`--valid-days 10`, `--out путь.pdf`.

Перед генерацией данные проверяются: контрольная цифра ИИН, 9 цифр в номере
удостоверения, формат даты выдачи. Отключить проверку: `--force`.

Шрифт Open Sans (`fonts/`) распространяется по лицензии Apache 2.0.
